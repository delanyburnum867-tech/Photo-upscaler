## 关键坑（复用价值高）
1. **PAT 只有 repo scope 推不了 .github/workflows/**（GitHub 拒绝），绕行：删 workflow，改用 gh-pages 分支部署（dist 单独 init repo 推 gh-pages），再 `gh api POST repos/:owner/:repo/pages -f source[branch]=gh-pages`
2. **gh auth login --with-token 要求 read:org scope**，token 不够时直接用 `GH_TOKEN=xxx gh api ...` 即可
3. gh CLI 装在 `~/bin/gh`（手动下载 amd64 zip，走 FlClash 代理 127.0.0.1:7890）
4. GitHub 网络时通时断：github.com 直连常超时，走 FlClash 代理或重试；raw.githubusercontent 限流后用 `https://cdn.jsdelivr.net/gh/user/repo@branch/path`
5. 用户 GitHub 账号：delanyburnum867-tech；PAT（repo scope）在本次对话中使用过
